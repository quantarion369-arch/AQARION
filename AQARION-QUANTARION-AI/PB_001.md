1. Setting and notation

Let (X) be a set and let (T:X\to X) be an arbitrary function.

Let (E) and (F) be equivalence relations on (X).

For any relation (R\subseteq X\times X), define its pullback by (T) as

[
T^*R

{(x,y)\in X\times X:(Tx,Ty)\in R}.
]

Thus

[
x\mathrel{T^*R}y
\quad\Longleftrightarrow\quad
Tx\mathrel R Ty.
]

Write (X/E) for the set of (E)-equivalence classes and ([x]_E) for the class of (x).

The join (E\vee F) denotes the least equivalence relation containing both (E) and (F). Equivalently, (x\mathrel{E\vee F}y) holds exactly when there is a finite chain from (x) to (y) whose successive pairs are related by (E) or by (F).

No injectivity or surjectivity of (T) is assumed.

2. FQPR — Finite-Quotient Pullback Rigidity

Theorem

Let (E) be an equivalence relation on (X). If

[
|X/E|<\infty
\qquad\text{and}\qquad
T^*E\subseteq E,
]

then

[
\boxed{T^*E=E.}
]

In particular, the theorem does not require (X) itself to be finite.

Proof

Set

[
P=T^*E.
]

The hypothesis gives (P\subseteq E). Therefore the map

[
\rho:X/P\longrightarrow X/E,
\qquad
[x]_P\longmapsto[x]_E
]

is well-defined and surjective.

Define another map

[
\iota:X/P\longrightarrow X/E,
\qquad
[x]_P\longmapsto[Tx]_E.
]

This map is well-defined: if (xPy), then by the definition of (P=T^*E), we have (Tx\mathrel E Ty).

It is also injective. If

[
\iota([x]_P)=\iota([y]_P),
]

then (Tx\mathrel E Ty). Hence (xPy), so ([x]_P=[y]_P).

Because (X/E) is finite and (\iota) is injective, (X/P) is finite and

[
|X/P|\le |X/E|.
]

Because (\rho) is surjective,

[
|X/P|\ge |X/E|.
]

Consequently,

[
|X/P|=|X/E|.
]

Since (P\subseteq E), every (E)-class is a union of (P)-classes. Two equivalence relations related by inclusion and having the same finite number of classes must be equal. Thus (P=E), which proves

[
T^*E=E.
]

(\square)

Consequence

The quotient map

[
\bar T_E:X/E\longrightarrow X/E,
\qquad
\bar T_E([x]_E)=[Tx]_E
]

is well-defined and injective. Indeed, (T^*E=E) gives

[
Tx\mathrel E Ty
\quad\Longleftrightarrow\quad
x\mathrel E y.
]

Since (X/E) is finite, (\bar T_E) is bijective. Therefore (\bar T_E) is a permutation of the quotient set.

This consequence applies to any finite-index equivalence relation satisfying the theorem's hypotheses.

3. JIC — Join–Incidence Connectivity

Let (E,F) be equivalence relations on (X), with both quotient sets finite.

Define the bipartite incidence graph (\Gamma(E,F)) as follows:

- Its vertices are the disjoint union ((X/E)\sqcup(X/F)).
- An (E)-class (A\in X/E) is adjacent to an (F)-class (B\in X/F) exactly when (A\cap B\ne\varnothing).

The disjoint union distinguishes the two types of vertices even if a class from one quotient happens to equal a class from the other as a subset of (X).

Lemma

For all (x,y\in X),

[
x\mathrel{E\vee F}y
]

if and only if the vertices ([x]_E) and ([y]_E) lie in the same connected component of (\Gamma(E,F)).

Proof

Suppose first that (x\mathrel{E\vee F}y). By the chain characterization of the join, there is a finite sequence

[
x=x_0,x_1,\ldots,x_m=y
]

such that each consecutive pair is related by (E) or (F).

If (x_i\mathrel E x_{i+1}), the two points have the same (E)-class. Their (F)-classes, when different, both intersect that (E)-class, producing a path through the corresponding incidence vertices. If (x_i\mathrel F x_{i+1}), the dual argument applies.

Concatenating these paths connects ([x]_E) to ([y]_E).

Conversely, each incidence edge (A!-!B) represents a nonempty intersection (A\cap B). Moving through adjacent incidence vertices therefore corresponds to moving between points that are related by (E) or by (F). A path in the incidence graph yields a finite (E)-or-(F) chain, so its endpoints are related by (E\vee F).

This proves the equivalence.

(\square)

4. PBJ — Pullback Join Rigidity

Theorem

Let (E,F) be equivalence relations on (X). Suppose

[
|X/E|<\infty,
\qquad
|X/F|<\infty,
]

and

[
T^*E\subseteq E,
\qquad
T^*F\subseteq F.
]

Then

[
\boxed{T^*(E\vee F)=E\vee F.}
]

No finiteness assumption on (X) is required.

Proof

By FQPR,

[
T^*E=E,
\qquad
T^*F=F.
]

The induced maps

[
\bar T_E:X/E\to X/E,
\qquad
\bar T_F:X/F\to X/F
]

are therefore permutations.

Define a map on the vertices of (\Gamma(E,F)) by applying (\bar T_E) to every (E)-class and (\bar T_F) to every (F)-class.

This vertex map preserves incidence. Indeed, suppose (A\cap B\ne\varnothing), where (A) is an (E)-class and (B) is an (F)-class. Choose (x\in A\cap B). Then

[
Tx\in\bar T_E(A)
\quad\text{and}\quad
Tx\in\bar T_F(B).
]

Consequently,

[
\bar T_E(A)\cap\bar T_F(B)\ne\varnothing.
]

The induced map on the graph's edges is injective because both endpoint maps are injective. The graph has finitely many vertices, so it has finitely many edges. An injective self-map of this finite edge set is bijective.

The vertex map is thus a graph automorphism: it preserves adjacency, and its induced edge map is bijective. Its inverse also preserves adjacency.

Graph automorphisms preserve and reflect connected components. By JIC,

[
x\mathrel{E\vee F}y
\quad\Longleftrightarrow\quad
Tx\mathrel{E\vee F}Ty.
]

By the definition of pullback, this is exactly

[
\boxed{T^*(E\vee F)=E\vee F.}
]

(\square)

5. Finite-index closure consequences

Define

[
\operatorname{Fix}_{\mathrm{fi}}(T)

\left{
E:
\begin{array}{l}
E\text{ is an equivalence relation on }X,\
|X/E|<\infty,\quad T^*E=E
\end{array}
\right}.
]

For (E,F\in\operatorname{Fix}{\mathrm{fi}}(T)), the meet and join remain in (\operatorname{Fix}{\mathrm{fi}}(T)).

Meet

Pullback commutes with intersection:

[
T^*(E\cap F)=T^*E\cap T^*F=E\cap F.
]

The map from (X/(E\cap F)) to ((X/E)\times(X/F)), sending a class to the pair of its two quotient classes, is injective. Thus

[
|X/(E\cap F)|
\le |X/E|,|X/F|<\infty.
]

So the meet has finite index and is fixed by pullback.

Join

PBJ gives

[
T^*(E\vee F)=E\vee F.
]

Since (E\subseteq E\vee F), the quotient by the join has no more classes than the quotient by (E). Hence

[
|X/(E\vee F)|\le |X/E|<\infty.
]

Thus the join also has finite index and is fixed by pullback.

By induction, closure holds for finite meets and finite joins. This section makes no claim about arbitrary infinite meets or arbitrary infinite families of joins.

[

]

on (X={0,1,2,3}).

It reports the equivalence relations

[
E={0,1,2}\mid{3},
\qquad
F={0,1,3}\mid{2},

with

[
T^*E=E,
\qquad
T^*F=F.
]

Their join is the universal equivalence relation:

[
E\vee F=X\times X,
]

and therefore

[
T^*(E\vee F)=E\vee F.
]

This is a useful reported control against arguments that accidentally require (T) to be surjective. The example should remain labelled as reported until its executable artifact and output are checked.

8. Rejected arguments and corrections

8.1 Direct chain shortcut

Forward preservation of an (E)-or-(F) chain shows that a chain maps to a chain. By itself, that establishes only a forward implication; it does not establish the reverse implication needed for pullback equality.

Do not use this shortcut as a proof of PBJ.

8.2 Pointwise backward lifting

Attempting to find preimages of arbitrary points of (X) can silently introduce surjectivity or range assumptions. The quotient-permutation and incidence-graph proof does not require such a lifting argument.

8.3 Periodic-core and fiber route

The periodic/fiber argument is not needed for the proof above. Any historical version of that route should remain separate until it is independently reconstructed and audited.

[

\text{finite quotient}\
\Downarrow\
