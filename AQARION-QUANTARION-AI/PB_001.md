AQARION PB-001″

Finite-Quotient Pullback Rigidity and Binary Join Closure

Status: ANALYTICALLY DERIVED · COMPUTATIONALLY SUPPORTED · LEAN OPEN · NOVELTY OPEN · NO PROMOTION

---

1. Setting

Let

[
T:X\to X
]

be an arbitrary function and let E,F be equivalence relations on X.

Define the pullback relation

[
T^*E

{(x,y)\in X^2:E(Tx,Ty)}.
]

The inclusion

[
T^*E\subseteq E
]

means that whenever the images Tx,Ty are E-equivalent, the original points x,y are already E-equivalent.

No injectivity or surjectivity of T is assumed.

---

2. FQPR — Finite-Quotient Pullback Rigidity

Theorem

If

[
|X/E|<\infty
]

and

[
T^*E\subseteq E,
]

then

[
\boxed{T^*E=E.}
]

Proof

Let

[
P=T^*E.
]

The hypothesis gives

[
P\subseteq E.
]

Therefore there is a natural surjection

[
\rho:X/P\to X/E,
\qquad
[x]_P\mapsto[x]_E.
]

Define

[
\iota:X/P\to X/E
]

by

[
\iota([x]_P)=[Tx]_E.
]

This is well-defined because

[
xPy
\iff
E(Tx,Ty).
]

It is injective because

[
\iota([x]_P)=\iota([y]_P)
]

implies

[
E(Tx,Ty),
]

hence

[
xPy.
]

Since X/E is finite, the injection implies that X/P is finite.

There is therefore both a surjection

[
X/P\twoheadrightarrow X/E
]

and an injection

[
X/P\hookrightarrow X/E.
]

The two finite quotient sets have equal cardinality.

Because P\subseteq E, equality of the finite numbers of classes forces

[
P=E.
]

Hence

[
\boxed{T^*E=E.}
]

No finiteness of X is required.

---

3. QPF — Quotient Permutation Factor

Under FQPR, define

[
\bar T_E:X/E\to X/E
]

by

[
\bar T_E([x]_E)=[Tx]_E.
]

Because

[
T^*E=E,
]

we have

[
Tx,E,Ty
\iff
x,E,y.
]

Thus \bar T_E is injective.

Since X/E is finite, it is bijective.

Therefore:

[
\boxed{
\bar T_E\text{ is a permutation of }X/E.
}
]

The same holds for F.

---

4. JIC — Join–Incidence Connectivity

Construct the bipartite graph

[
\Gamma(E,F)
]

whose vertex set is

[
(X/E)\sqcup(X/F).
]

An E-class A and an F-class B are adjacent exactly when

[
A\cap B\neq\varnothing.
]

Lemma

For x,y\in X,

[
\boxed{
x(E\vee F)y
\iff
[x]_E\text{ and }[y]_E
\text{ lie in the same connected component of }\Gamma(E,F).
}
]

Proof sketch

An E-edge keeps the E-class fixed and moves through a common F-class.

An F-edge does the dual operation.

Therefore an alternating path in the incidence graph corresponds exactly to a finite chain whose successive pairs are related by either E or F.

The equivalence relation generated by E\cup F is precisely E\vee F.

5. PBJ — Pullback Join Rigidity

Assume

[
|X/E|<\infty,
\qquad
|X/F|<\infty,
]

and

[
T^*E\subseteq E,
\qquad
T^*F\subseteq F.
]

By FQPR,

[
T^*E=E,
\qquad
T^*F=F.
]

Hence quotient permutations exist:

[
\bar T_E:X/E\to X/E,
]

[
\bar T_F:X/F\to X/F.
]

Suppose

[
A\cap B\neq\varnothing.
]

Choose

[
x\in A\cap B.
]

Then

[
Tx\in\bar T_E(A)
]

and

[
Tx\in\bar T_F(B).
]

Hence

[
\bar T_E(A)\cap\bar T_F(B)\neq\varnothing.
]

Thus quotient permutations induce a self-map of the finite edge set of \Gamma(E,F).

The map is injective because both endpoint maps are injective.

The edge set is finite because both quotient vertex sets are finite.

Therefore the edge map is bijective.

Hence the induced vertex map is a graph automorphism.

Graph automorphisms preserve and reflect connected components.

By JIC,

[
x(E\vee F)y
\iff
Tx(E\vee F)Ty.
]

Therefore

[
\boxed{
T^*(E\vee F)=E\vee F.
}
]

No finiteness of X is required.

6. Finite-index closure consequences

Define

[
\operatorname{Fix}_{\mathrm{fi}}(T)

\left{
E:
E\text{ is an equivalence relation},
\ |X/E|<\infty,
\ T^*E=E
\right}.
]

For E,F\in\operatorname{Fix}_{\mathrm{fi}}(T):

Meet

[
T^*(E\cap F)

T^*E\cap T^*F

E\cap F.
]

Moreover,

[
|X/(E\cap F)|
\le
|X/E|,|X/F|.
]

Thus the meet remains finite-index.

Join

PBJ gives

[
T^*(E\vee F)=E\vee F.
]

Since

[
E\subseteq E\vee F,
]

the join has no more classes than E, so

[
|X/(E\vee F)|\le|X/E|<\infty.
]

Therefore binary meets and joins remain inside the finite-index fixed-point regime.

Finite joins and finite meets follow by induction.

No claim is made here about arbitrary infinite meets or arbitrary infinite families without a separate proof.

8. Non-surjective control

The theorem does not require T to be surjective.

For

[
T=(0,0,2,3)
]

on

[
X={0,1,2,3},
]

the map is non-surjective.

Nevertheless,

[
E={0,1,2}\mid{3}
]

and

[
F={0,1,3}\mid{2}
]

satisfy

[
T^*E=E,
\qquad
T^*F=F.
]

Their join is universal:

[
E\vee F=X\times X,
]

and consequently

[
T^*(E\vee F)=E\vee F.
]

This confirms that the theorem is genuinely quotient-level.

9. Rejected arguments

Direct chain shortcut

Forward preservation gives

[
E/F\text{-chain}
\Longrightarrow
T(E/F)\text{-chain}.
]

Therefore

[
E\vee F\subseteq T^*(E\vee F).
]

This is the wrong direction for applying FQPR.

It is not a proof of PBJ.

Pointwise backward lifting

Attempting to recover preimages of arbitrary points of X implicitly introduces a range condition or surjectivity assumption.

That route is unnecessary and is quarantined.

Fiber/periodic-core route

The periodic/fiber argument is not required for PBJ and remains a historical/quarantined route until independently reconstructed.

Final disposition

The adversarial attack did not kill PBJ.

It improved it.

The strongest current statement is:

[
\boxed{
\begin{aligned}
&|X/E|<\infty,\ |X/F|<\infty,\
&T^*E\subseteq E,\ T^F\subseteq F
\[2mm]
&\Longrightarrow
T^(E\vee F)=E\vee F.
\end{aligned}
}
]

The carrier X need not be finite.

The proof mechanism is not pointwise invertibility.

It is:

[
\boxed{
\text{finite quotients}
\rightarrow
\text{quotient permutations}
\rightarrow
\text{finite incidence graph}
\rightarrow
\text{graph automorphism}
\rightarrow
\text{join rigidity}.
}
]

This is the current analytic center of PB-001″.
