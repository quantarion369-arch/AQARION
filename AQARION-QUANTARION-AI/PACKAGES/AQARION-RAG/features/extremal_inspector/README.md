# Extremal dynamics case inspector

Installed as an additional page in the existing AQARION-RAG workbench at `/cases/extremal`.

`recognizer.py` is the reusable implementation. `build-001/` preserves the original checked build unchanged, including its historical pre-integration scope statements.

The page displays exact saved cases, not arbitrary live computations. Browser interaction remains a user check.

## Constructive terminal repair

The case route now serves build-002. Historical build-001 is unchanged. Nonliteral terminals include an integer Möbius/parity repair certificate, checked by direct subset sums and parity moments.

## Bounded live analysis

The separate page `/cases/extremal/live` submits JSON to `POST /api/cases/extremal/analyze`.

Only two, four, or eight states and binary observations are accepted. Request bodies are limited to 2048 bytes. Exact ranks use the fixed checksum-pinned preserved reference. Unavailable reference code produces a controlled service error without changing retrieval.

Live computations are fresh, not atlas lookups. Results are not automatically saved. Input is never treated as code or a filesystem path. This is a local bounded feature, not a general solver or a complete security certification.
