# Constructive terminal repair extension

Extends build-001 without recalculating its ranks or changing its historical recognition fields.

Eight distinct nonliteral saved cases receive independently checked integer parity-moment certificates.

A certificate supplies the missing top-monomial direction relative to the proper prefix monomials. Its detecting feature degree is not necessarily the degree where all functions become recoverable.

Reproduction command, using a fresh output directory:

python enrich_cases.py FEATURE_DIRECTORY OUTPUT_DIRECTORY [RECOGNIZER_FILE]
