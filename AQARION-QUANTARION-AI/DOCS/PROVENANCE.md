## Purpose

This file will define the relationship between claims, source code,
execution records, artifact hashes, and evidence artifacts.

## Core principle

A hash establishes artifact identity, not mathematical truth. A receipt
must be tied to the actual artifact and execution it claims to describe.
The existence of a source file, test, badge, or report is not by itself
sufficient evidence for a claim's status.
