## 1. Mathematical claim

Let `X` be a finite nonempty set, let `T : X -> X` be a
total map, and let `Pi = {B_1, ..., B_k}` be a partition of `X`
into `k` nonempty blocks.

Use the Koopman matrix convention

    K[x,y] = 1 iff T(x) = y

and the orthogonal block-average projector

    P[x,y] = 1/|B| when x,y belong to the same block B,
             0 otherwise.

The canonical defect operator is

    D = (I - P) K P.

Construct the target-block co-occurrence graph `H_Pi`:

- one vertex for each partition block;
- for each source block, connect every pair of distinct target
  blocks hit by the image of that source block;
- retain all vertices, including isolated vertices.

The claim is

    rank(D) = k - c(H_Pi),

where `c(H_Pi)` counts every connected component, including
isolated vertices.

## 2. Proof outline

The range of `P` is the space of functions constant on each
partition block. Because `D = D P`, the defect rank is determined
by the restriction of `D` to that `k`-dimensional space.

For a block-constant function `h`, `D h = 0` precisely when
`K h` is block-constant.

If two states in the same source block map into different target
blocks, their target block-values must agree for `D h = 0`.
These are exactly the equalities generated by the edges of
`H_Pi`.

Consequently, the kernel of the restricted defect consists of
functions constant on each connected component of `H_Pi`. Its
dimension is `c(H_Pi)`. Rank-nullity gives

    rank(D) = k - c(H_Pi).

This is a mathematical proof outline. The Python audit is a
separate computational evidence layer; it does not replace the
proof or a Lean formalization.

## 3. Mutation semantics

SM003 has two different mutation classes. Their detection rules
must not be mixed.

### D-level mutants: Boolean zero-tests

Each D-level mutant evaluates an explicit operator predicate.
Its verdict is whether that operator is exactly zero.

A D-level mutant is detected on an instance if and only if its
zero/nonzero verdict differs from the independent combinatorial
closure oracle.

The transpose-defect test is

    (I - P) K^T P = 0.

It is not the expression `rank(K^T)`, which computes the rank
of the Koopman matrix transpose rather than the transpose defect.

The commutator test is

    K P - P K = 0.

The expression `K P (I - P)` is identically zero because
`P(I - P) = 0`. It is retained as a deliberately degenerate,
always-accepting mutant. It is not interchangeable with

    P K (I - P) = ((I - P) K^T P)^T.

### R-level mutants: candidate rank formulas

Graph-level alternatives produce candidate rank values. They
are detected if their predicted rank differs from the exact
matrix rank of `D`.

The canonical alternatives are:

- `R:ignore-isolated`
- `R:preimage`
- `R:c`
- `R:k-c-1`
- `R:first`

`R:c-only-variant` duplicates `R:c`. It is invalid and earns
no mutation-coverage credit.

The former `R:ignore+preimage_cluster` label is not a canonical
mutant. Its members are independently evaluated and reported.
Equal detection sets over a bounded census, if observed, establish
only bounded agreement—not universal equivalence.

## 5. Exact arithmetic and independent oracle

`mutations.py` uses `fractions.Fraction` for matrix entries and
Gaussian elimination. It does not use NumPy or floating-point
rank tolerances.

The combinatorial closure oracle checks directly whether every
source block maps wholly into one target block. It does not
derive closure truth from the defect matrix.

The graph computation independently constructs the target-block
image groups, retains isolated vertices, and counts components.

The regression test compares the complete recomputed witness
detection set with the manifest declaration. It fails for:

- an unknown mutant identifier;
- a declared false-positive detection;
- an omitted detection;
- coverage credited to an invalid mutant;
- a mismatch in the pinned W1/W2 matrix.

## 7. Replay commands

Run from the repository root.

First generate the exhaustive report:

    python3 AQARION-QUANTARION-AI/verification/SM/SM003/mutations.py \
      --max-n 4 \
      --report AQARION-QUANTARION-AI/verification/SM/SM003/sm003-mutation-report.json

Then run the regression suite:

    python3 -m unittest discover \
      -s AQARION-QUANTARION-AI/verification/SM/SM003 \
      -p test_sm003.py -v

Both commands must complete successfully. The witness test must
match the manifest exactly. Do not change expected detections
merely to make a failed assertion pass.

## 8. Provenance and evidence boundary

The manifest deliberately leaves source revision, environment,
hashes, output streams, exit codes and runtime unpopulated until
they are obtained from an actual replay.

After replay, record:

- tested Git commit SHA;
- Python version, implementation, platform and dependencies;
- exact commands;
- stdout and stderr;
- exit codes and runtime;
- SHA-256 hashes of the tested source files;
- SHA-256 hash of the retained report;
- whether every regression assertion passed.

A generated report is evidence only for the code and finite scope
that actually produced it.

`PASS` means the baseline matrix-rank identity agrees with the
graph prediction over the executed finite scope. It does not
certify every mutant, prove a universal theorem by computation,
establish Lean verification, or authorize a frozen release.

The workflow is unchanged. No new workflow file is required.
