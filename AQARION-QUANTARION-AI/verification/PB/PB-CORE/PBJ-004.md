Finite-Quotient Pullback Join Rigidity

Status: FROZEN ANALYTIC ROUTE · FORMALIZATION OPEN · NO PROMOTION

1. PBJ-001 — Finite-Quotient Pullback Rigidity

For an equivalence relation E on X, define

[
T^*E={(x,y):(Tx,Ty)\in E}.
]

If

[
|X/E|<\infty
]

and

[
T^*E\subseteq E,
]

then

[
\boxed{T^*E=E.}
]

No finiteness assumption on X is required.

Proof architecture:

[
P=T^*E\subseteq E.
]

The canonical map

[
X/P\to X/E
]

is surjective.

The map

[
X/P\to X/E,\qquad [x]_P\mapsto[Tx]_E
]

is well-defined and injective.

Since X/E is finite,

[
|X/P|=|X/E|,
]

hence

[
P=E.
]

---

2. PBJ-002 — Finite Quotient Incidence Graph

Assume

[
|X/E|<\infty,\qquad |X/F|<\infty.
]

Construct the bipartite graph

[
\Gamma(E,F)
]

with vertex set

[
(X/E)\sqcup(X/F)
]

and incidence relation

[
A\sim B
\iff
A\cap B\neq\varnothing.
]

The graph is finite.

---

3. PBJ-003 — Join/Component Correspondence

For x\in X, let

[
v_x
]

denote the corresponding pair of quotient classes

[
([x]_E,[x]_F).
]

Then

[
\boxed{
x(E\vee F)y
\iff
v_x\text{ and }v_y
\text{ lie in the same connected component of }\Gamma(E,F).
}
]

This is the standard equivalence-closure/incidence-graph characterization of the join.

---

4. PBJ-004 — Induced Quotient Maps

Assume

[
T^*E=E,\qquad T^*F=F.
]

Define

[
\bar T_E([x]_E)=[Tx]_E,
]

and

[
\bar T_F([x]_F)=[Tx]_F.
]

By PBJ-001, both quotient maps are bijections.

Define

[
\Phi:
(X/E)\sqcup(X/F)
\to
(X/E)\sqcup(X/F)
]

by

[
\Phi(A)=\bar T_E(A),
]

on the E-side, and

[
\Phi(B)=\bar T_F(B),
]

on the F-side.

Then

[
\Phi(v_x)=v_{Tx}.
]

---

5. PBJ-005 — Incidence-Graph Automorphism

If

[
A\cap B\neq\varnothing,
]

choose

[
x\in A\cap B.
]

Then

[
Tx\in\bar T_E(A)\cap\bar T_F(B),
]

so

[
\Phi(A)\cap\Phi(B)\neq\varnothing.
]

Because both quotient maps are bijective, the converse follows by applying their inverses.

Therefore

[
\boxed{
A\cap B\neq\varnothing
\iff
\Phi(A)\cap\Phi(B)\neq\varnothing.
}
]

Hence

[
\boxed{
\Phi:\Gamma(E,F)\cong\Gamma(E,F)
}
]

is a graph automorphism.

---

6. PBJ-006 — Component Equivalence Under the Automorphism

This is the corrected load-bearing statement.

Do not require

[
\Phi(C)=C.
]

The required statement is

[
\boxed{
\Gamma.\operatorname{Reach}(v,w)
\iff
\Gamma.\operatorname{Reach}(\Phi(v),\Phi(w)).
}
]

Equivalently,

[
\boxed{
\operatorname{Comp}(v)=\operatorname{Comp}(w)
\iff
\operatorname{Comp}(\Phi(v))

\operatorname{Comp}(\Phi(w)).
}
]

Proof:

- a graph automorphism maps every path to a path;
- its inverse maps paths back;
- therefore reachability is preserved and reflected.

In Mathlib terminology, this is directly represented by the "SimpleGraph.Iso" reachability and connected-component APIs.

---

7. PBJ-007 — Pullback Fixity of the Join

Using PBJ-003 and PBJ-006,

[
\begin{aligned}
x(E\vee F)y
&\iff
\Gamma.\operatorname{Reach}(v_x,v_y)\
&\iff
\Gamma.\operatorname{Reach}(\Phi(v_x),\Phi(v_y))\
&\iff
\Gamma.\operatorname{Reach}(v_{Tx},v_{Ty})\
&\iff
Tx(E\vee F)Ty.
\end{aligned}
]

Therefore

[
(x,y)\in T^*(E\vee F)
\iff
(x,y)\in E\vee F.
]

Hence

[
\boxed{
T^*(E\vee F)=E\vee F.
}
]

---

Final theorem

For arbitrary X, if

[
|X/E|<\infty,\qquad |X/F|<\infty,
]

and

[
T^*E=E,\qquad T^*F=F,
]

then

[
\boxed{
T^*(E\vee F)=E\vee F.
}
]

No assumption that T:X\to X is surjective is required.

No assumption that each individual join component is fixed is required.

The graph automorphism may permute components.
