## Exact observation criterion over Q

Let Kf=f composed with T, and let Kbar act on Vbar=Q^X/Q*1.
Write hbar for the observation class.

Let m_hbar be the monic polynomial of least degree satisfying

    m_hbar(Kbar) hbar = 0.

For hbar=0, use m_hbar=1. Then

    dim span{1,h,Kh,K^2h,...} = 1 + degree(m_hbar).

Indeed, modulo the constant line the temporal space is precisely the
cyclic subspace generated by hbar.

The observation attains maximum temporal rank exactly when

    m_hbar = m_Kbar.

The vector polynomial divides the operator polynomial, so attaining
the same degree forces equality of the monic polynomials.

## Operator polynomial from the functional graph

Let nu be maximum transient depth, c the number of components, and

    P_T(z) = lcm_i(z^li-1)

for the cycle lengths li. In characteristic zero,

    m_Kbar(z) = z^nu P_T(z)/(z-1),  if c=1;
    m_Kbar(z) = z^nu P_T(z),        if c>=2.

Quotienting removes the sole eigenvalue-1 direction when c=1.
For c>=2 a fixed direction remains, so that factor remains.

## Explicit four-cycle

For T=(1,2,3,0),

    m_Kbar=(z+1)(z^2+1).

For h=(0,1,3,2),

    m_hbar=z^2+1,
    temporal rank=3,
    h composed with T^2 + h = 3*1.

For h=(0,1,2,3),

    m_hbar=(z+1)(z^2+1),
    temporal rank=4.

For constant h, m_hbar=1 and temporal rank=1.

These polynomial identities are written certificates. The current
fixture checker checks the corresponding nonconstant matrix ranks,
not a general minimal-polynomial implementation.

## Rank and observability: corrected implication

Full temporal row rank implies observability: equal histories would
give equal rows and therefore dependence.

Observability does not imply full temporal row rank.

Do not describe these two properties as failing to imply each other
in both directions.

## Rational quotient coordinates

Choose anchor state x0. Represent f modulo constants by

    q(f)_x=f(x)-f(x0), x!=x0.

Then, for x,y!=x0,

    Kbar[x,y]=indicator(T(x)=y)-indicator(T(x0)=y).

An exact first-dependence calculation on
q(h),Kbar*q(h),... gives the vector polynomial and a recurrence
certificate without numerical eigenvectors.
