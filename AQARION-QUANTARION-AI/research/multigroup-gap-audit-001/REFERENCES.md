# Supporting literature

These references provide background; they do not certify this experiment.

- Edward F. Moore, Gedanken-experiments on sequential machines (1956).
  https://www.jstor.org/stable/j.ctt1bgzb3s.8
  Context: behavioral distinguishability. Full chapter not reviewed here.

- John E. Hopcroft, An n log n algorithm for minimizing states in a finite
  automaton, Stanford technical report CS-TR-71-190 (1971).
  https://www.cs.cmu.edu/~cdm/resources/Hopcroft1971.pdf
  Context: automaton minimization and partition refinement.

- R. E. Kalman, Mathematical Description of Linear Dynamical Systems (1963).
  https://doi.org/10.1137/0301010
  Context: observability and linear realization.

- J. W. Carlyle and A. Paz, Realizations by stochastic finite automata (1971).
  https://doi.org/10.1016/S0022-0000(71)80005-3
  Context: finite-rank behaviors and weighted realizations.
  No Hankel-rank equivalence is claimed for this package.

- NIST DLMF, Section 26.7: Set Partitions: Bell Numbers.
  https://dlmf.nist.gov/26.7

- NIST DLMF, Section 26.8: Set Partitions: Stirling Numbers.
  https://dlmf.nist.gov/26.8
