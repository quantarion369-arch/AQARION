# Separating-register verification

Preserves two completed standalone Termux executions.

## Cubic certificates

Three eight-state binary fixtures have exact rational rank profile [1,4,7,8], a quadratic annihilator, and a nonzero cubic witness. Source, results, proof note, and logs are preserved in cubic-exact-001/.

## Register classification

The preserved run checks binary register descriptions through dimension five, image sizes, core orders, exact cube ranks, and canonical encoding recovery and uniqueness.

Complete represented-map lists contain 4,608 eight-state binary maps and 3,240 nine-state ternary maps. Exhaustive all-map comparisons were performed only on two- and four-state binary systems.

## Evidence boundaries

These are preserved executions, not new computations. Original files and checksum manifests are unchanged.

The spectral equality theorem is an external mathematical dependency. This package does not machine-prove it, exhaust all eight-state maps, certify literature novelty, or authorize claim promotion.

The successful validator CI is a separate software checkpoint; it did not execute these research experiments.
