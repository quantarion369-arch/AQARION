# AQARION-CORE

Core module for the AQARION system providing essential functionality for audit, status tracking, and data models.

## Features

- **Models**: Data structures for core entities
- **Status Management**: Track and manage system status
- **Audit Logging**: Comprehensive audit trail functionality

## Installation

```bash
pip install aqarion-core
```

## Usage

```python
from aqarion_core import models, status, audit

# Use core functionality
```

## Testing

```bash
pytest tests/
```
