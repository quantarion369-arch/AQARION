# JOIN-STABILITY ZIP and Clone Reproduction

## Preferred method: Git checkout

A Git checkout is required for the package's source-baseline ancestry
check.

From the package directory, run:

    AQ_EXPECTED_TESTED_REVISION="<full-tested-commit-sha>" bash reproduce.sh

The expected tested revision must come from a trusted external source,
such as the independently inspected checkout or CI job. Do not set it
from an unverified value generated by the same process being tested.

## ZIP-only copies

A ZIP archive may not contain Git history. Without the repository
metadata, the verifier cannot prove that the declared source baseline
is an ancestor of the tested revision.

The package must therefore fail closed rather than silently treating a
manifest string as proof of provenance.

For a ZIP-only review, use a separately documented process that records:

- the archive's origin and URL;
- the exact archive SHA-256;
- the source commit associated with the archive, if independently known;
- the hashes of all package files;
- the commands executed and their exit codes;
- the fact that Git ancestry could not be checked.

Do not describe a ZIP-only structural check as a full provenance pass.

## Scope of reproduction

A successful reproduction run establishes only the checks that were
actually executed and passed. The script does not compile Lean or
independently review the mathematical proofs.
