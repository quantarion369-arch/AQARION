3. FORWARD STABILITY

For an equivalence relation E,

[
xEy\Longrightarrow T(x)ET(y)
]

is the forward/congruence condition.

For a partition \Pi, the corresponding operator statement is

[
D_\Pi=0.
]

The central quotient equivalence is:

[
\boxed{
D_\Pi=0
\iff
K_T(V_\Pi)\subseteq V_\Pi
\iff
T\text{ descends to }X/\Pi.
}
]

This is the observable quotient side of AQARION.

Forward-stable equivalences are ordinary congruences for the unary algebra generated by T. This surrounding universal-algebra structure is established mathematics and must not be claimed as AQARION's novel discovery.

AQARION's contribution is instead centered on the exact operator and quantitative/incidence structure developed below.

4. EXACT DEFECT-RANK THEOREM

Let \Gamma(T,\Pi) be the graph whose vertices are the partition blocks.

Connect target blocks B_j,B_k whenever some source block B_i contains points x,y such that

[
T(x)\in B_j,
\qquad
T(y)\in B_k.
]

Let

[
c(\Gamma)
]

be the number of connected components.

Then the core rank identity is

[
\boxed{
\operatorname{rank}D_\Pi

m-c(\Gamma).
}
]

The proof proceeds through the coefficient representation of V_\Pi:

[
f=\sum_{j=1}^m a_j1_{B_j}.
]

The condition

[
Df=0
]

forces equality of coefficients across every pair of target blocks jointly hit by a source block.

These are precisely the equality constraints represented by the graph.

Thus

[
\dim\ker(D|{V\Pi})=c(\Gamma)
]

and rank-nullity gives the theorem.

5. SHARP FINITE RANK BOUND

The defect graph has m vertices, hence

[
\operatorname{rank}D_\Pi\le m-1.
]

If source block B_i has size s_i, it can hit at most s_i target blocks.

Therefore its contribution to independent graph connectivity is at most

[
s_i-1.
]

Summing:

[
\operatorname{rank}D_\Pi
\le
\sum_i(s_i-1)

n-m.
]

Hence

[
\boxed{
\operatorname{rank}D_\Pi
\le
\min(m-1,n-m).
}
]

Optimizing over m:

[
\boxed{
\max_{T,\Pi}\operatorname{rank}D_\Pi

\left\lfloor\frac{n-1}{2}\right\rfloor.
}
]

This is a theorem target and must be maintained separately from finite computational census evidence.

6. BACKWARD / PULLBACK STABILITY

For an equivalence relation E,

[
T(x)ET(y)\Longrightarrow xEy.
]

Equivalently,

[
\boxed{
T^{-1}(E)\subseteq E.
}
]

This is not the same statement as forward congruence.

The finite theorem kernel therefore maintains two separate notions:

FORWARD
x E y  →  T(x) E T(y)

BACKWARD
T(x) E T(y)  →  x E y

Confusing these directions is a prohibited kernel error.

7. FINITE KERNEL-EQUALITY LEMMA

Let

[
q_E:X\to X/E
]

be the quotient map.

Define

[
S_E=q_E\circ T.
]

If

[
T(x)ET(y)\Longrightarrow xEy,
]

then

[
\ker S_E\subseteq E.
]

Because X is finite,

[
|X/E|
\le
|X/\ker S_E|

|\operatorname{im}S_E|
\le
|X/E|.
]

Therefore equality holds and

[
\boxed{
\ker(q_E\circ T)=E.
}
]

Consequently:

[
\boxed{
xEy
\iff
T(x)ET(y).
}
]

This lemma is the hinge of the finite JOIN-STABILITY theorem.

8. FINITE QUOTIENT-PERMUTATION THEOREM

Under finite pullback stability,

[
T^{-1}(E)\subseteq E,
]

the induced map

[
\bar T_E([x]_E)=[T(x)]_E
]

is well-defined.

Finite kernel equality gives injectivity.

Since X/E is finite:

[
\boxed{
\bar T_E:X/E\to X/E
\text{ is a permutation}.
}
]

This converts the pullback-stability problem into finite permutation dynamics.

9. INCIDENCE-GRAPH JOIN THEOREM

For equivalences E,F, construct the simple bipartite incidence graph

[
G(E,F)
]

with vertex set

[
X/E\sqcup X/F.
]

There is an edge between A\in X/E and B\in X/F exactly when

[
A\cap B\ne\varnothing.
]

The connected components of this graph are exactly the blocks of

[
E\vee F.
]

If E and F are pullback-stable on finite X, then

[
\bar T_E,\bar T_F
]

are permutations.

Their product therefore gives a bijection of the bipartite vertex set.

It maps incidence edges to incidence edges.

Because the graph is finite, the induced edge map is a graph automorphism.

Therefore connected components are preserved.

Hence:

[
\boxed{
T^{-1}(E)\subseteq E
\land
T^{-1}(F)\subseteq F
\Longrightarrow
T^{-1}(E\vee F)\subseteq E\vee F
}
]

for finite X.

This is the principal JOIN-STABILITY theorem target.
